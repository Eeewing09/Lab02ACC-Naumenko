                 Ответы на контрольные вопросы
1) IL — это промежуточный код, в который C# превращается после компиляции. Он нужен для кроссплатформенности, чтобы программа могла одинаково запускаться на Windows, Linux и macOS, полсе он превращается в машинный код.
2) Внутри .dll хранится не машинный код, а IL-код, что позволяет его легко декомпилировать
3) В Debug присутствуют пустые инструкции nop для работы отладчика, а в Release они полностью удалены. Кроме того, в Release-версии компилятор убрал некоторые переменные, сократив код метода Add с 10 до 4 инструкций.
4) В Release включается оптимизация компилятора, которая убирает отладочные переменные и значения
5) Любой текст из кода записывается в файл .dll в открытом и незашифрованном виде. Его можно мгновенно увидеть через декомпилятор
